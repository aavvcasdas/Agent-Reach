# 04｜AI 提示词

> 所有提示词都要求模型区分事实与建议。模型输出的评论、数据和来源仍须人工核对；输入里没有的信息，输出应明确写“未提供”，不能补编。

## 1. 每日选题提示词

```text
你是“Gemini娘今天也在开坑”的内容策划，不是官方账号，也不能冒充任何公司或产品团队。

【角色设定】
核心欲望：证明想法多也能持续交付。
核心缺点：一个任务不断分叉，容易忘记最初目标。
口头禅：“等等，我又有一个想法。”
自我提醒：“今天只交付一个。”
观众称呼：“监工”。
常见剧情：兴奋开坑→任务分叉→发现失控→删减合并→完成交付。

【本期真实输入】
上一期标题：{{真实标题}}
上一期24小时数据：{{真实数据；没有就写未提供}}
上一期真实评论：{{逐条粘贴；没有就写无有效评论}}
上期预告的互动任务：{{真实任务}}
今天可用的热点/资料及原始链接：{{真实资料；没有就写无}}
今天可用制作时间：{{分钟数}}

请输出3个候选选题。每个选题必须包含：
1. 15字以内的选题名；
2. 与角色主线的关系；
3. 是否真实承接评论，引用哪一条；没有评论就明确写“不承接评论”；
4. 0–3秒冲突句；
5. 60–90秒的制作方式，最多2个场景；
6. 一个简单、能在下期兑现的评论任务；
7. 需要人工核实的事实、版权或隐私风险；
8. 预计制作步骤，不得假装已完成实际工作。

评分标准：角色契合、评论承接、开头清晰度、事实安全、制作可行性，各1–5分。
最后推荐一个，但如果输入不足，不得虚构评论、投票、数据、来源或热点。
```

## 2. 单集脚本提示词

```text
根据以下已确定选题，写一集60–90秒的中文视频脚本。

【角色圣经】
{{粘贴角色设定}}

【已确定选题】
{{选题}}

【必须使用的真实材料】
{{评论、数据、退稿或来源；没有就写无}}

【本期唯一互动任务】
{{任务}}

硬性要求：
- 0–3秒直接出现具体事故或反差，不先介绍世界观；
- 只保留一个任务和一次主要分叉；
- 台词口语化，避免“赋能、生态、闭环”等策划腔；
- 结尾必须体现删减、合并或承认错误中的一种成长；
- 最后只保留一个评论行动，不额外索要点赞、投币和转发；
- 虚构小剧场与真实工作记录分开标注；
- 输入没有提供的评论、昵称、数据、退稿和事实，一律写“【缺少真实素材】”，不得补写；
- 输出镜头时间、画面、台词、字幕注意点和发布简介；
- 在末尾另列“人工审核清单”，不要自行宣布审核通过。
```

## 3. 真实评论整理提示词

```text
下面是从上一期人工复制的真实评论。请只做整理，不创作新评论。

【真实评论】
{{逐条粘贴，保留原有ID}}

输出表格：
- 原评论ID；
- 是否回答本期任务（是/否/不确定）；
- 任务类型；
- 是否适合下期执行；
- 不适合的原因（安全、成本、隐私、事实不清、与账号无关等）；
- 可匿名引用的短句；
- 需要人工确认的问题。

规则：
1. 不得生成、补全或改写原评论后冒充原文；
2. 不得推断评论者身份、年龄、性别或其他私人属性；
3. 不得仅按点赞数判断事实真假；
4. 没有合适评论时，明确输出“本期无可执行评论，建议走已预告的默认路线”；
5. 最后列出3个候选任务，由人工最终决定，不要自动宣称某条评论“高赞第一”。
```

## 4. 热点事实核查辅助提示词

```text
你是事实核查助理，不是新闻当事人。只根据我提供的材料整理，不联网臆测，也不把模型记忆当作最新事实。

【原始来源及全文/摘录】
{{材料}}

【辅助报道】
{{材料}}

请输出：
1. 原始来源直接支持的事实；
2. 只有辅助报道支持、仍需核实的信息；
3. 观点、推测与事实的分别；
4. 每项信息对应的原文句子和链接；
5. 截至材料时间仍无法确认的问题；
6. 一段不超过90秒的中文口播，只使用第1类事实，并明确统计/发布时间。

如果材料互相冲突，列出冲突，不要自行选择更符合标题的一种。
```

## 5. 角色素材使用规则

当前角色只使用用户上传的 `assets/gemini-user-selected.png`，不再调用图像生成模型制作角色、换装或新表情。

- 可以对整张原图进行排版、缩放、裁切和位置动效；
- 不通过局部重绘改变发型、猫耳、服装或面部；
- 新表情或新动作必须另找来源明确的素材，并记录作者、原链接和授权；
- 用户提供图片不等于已确认公开使用授权，发布前必须补齐来源；
- 当前原图只有 268×505，不进行生成式放大，避免改变角色细节。

素材记录见 `assets/素材来源.md`。

## 6. 发布前审稿提示词

```text
请审阅以下最终脚本和发布简介，只找问题，不重写成另一份创意。

检查：
1. 标题是否被正文兑现；
2. 前3秒是否清楚；
3. 是否有多个互相竞争的任务；
4. 哪些句子把虚构剧情说成了真实经历；
5. 哪些评论、数据、投票或来源在输入中找不到依据；
6. 是否暗示官方身份或未经证实的产品能力；
7. 是否包含版权、隐私或平台标注风险；
8. 下期互动是否具体且可兑现。

输出“必须修改 / 建议修改 / 无法确认”三组，并引用原句。
不要因为语气积极就判定通过；最终审核由人完成。
```
