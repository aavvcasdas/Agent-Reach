# Gemini娘账号启动包

版本：v1.0（2026-10-22）

## 一句话定位

**一个想法永远比时间多的 Gemini 非官方二创角色，挑战 7 天学会“每天只交付一件事”；评论区当监工，数据、退稿和翻车都公开。**

推荐账号名：**Gemini娘今天也在开坑**

这套启动包按以下条件设计：B站、每天一条 60–90 秒视频、立绘＋配音＋轻动画、AI 辅助生产、人类审核并发布。

## 文件清单

| 文件 | 用途 |
|---|---|
| `01-账号与人设.md` | 账号名、简介、角色圣经、视觉与语言规范 |
| `02-首周脚本.md` | Day 0–6 的标题、台词、分镜和互动设计 |
| `03-生产与发布SOP.md` | 每天从调研到复盘的执行流程与检查表 |
| `04-AI提示词.md` | 选题、脚本、评论整理和形象生成提示词 |
| `templates/每日制作单.md` | 每天复制一份，避免漏掉来源、审核和互动兑现 |
| `data/每日数据复盘.csv` | 真实数据记录表，不含任何预填或伪造数据 |
| `assets/gemini-user-selected.png` | 用户指定的角色原图；不重绘，作者与授权信息待补 |
| `assets/素材来源.md` | 当前素材来源、授权待补项与使用边界 |
| `production/day0/Day0-Gemini娘-视频草稿.mp4` | 已合成的 Day 0 草稿：1080p、约64秒、配音与内嵌字幕 |
| `production/day0/Day0-cover.png` | Day 0 封面草稿 |
| `production/day0/Day0-Gemini娘-字幕.srt` | 可单独导入剪辑软件的字幕 |

## 今天如何开拍

1. 阅读 `01-账号与人设.md`，确定账号名、简介和角色边界。
2. 当前角色使用用户指定的 `assets/gemini-user-selected.png`，不自行生成或重绘；正式发布前补齐原作者和授权信息。
3. Day 0 已输出到 `production/day0/Day0-Gemini娘-视频草稿.mp4`，先试看草稿；后续视频不要提前把七天全部做完。
4. 按 `03-生产与发布SOP.md` 制作、审核并人工发布，按平台要求标注 AI 生成/二创/虚构剧情。
5. 发布后收集真实评论。第二天先兑现评论任务，再制作下一条。
6. 每天把真实后台数据填入 `data/每日数据复盘.csv`，第七天决定继续、调整还是停止。

## 核心运营闭环

```text
真实评论/热点资料
      ↓
AI 提出 3 个选题
      ↓
人类筛选、核实、修改
      ↓
60–90 秒角色小剧场
      ↓
结尾只留一个互动任务
      ↓
下期真实采纳并署名反馈
      ↓
公开数据与失败，再进入下一轮
```

## 三条硬规则

- **不伪造互动**：没有评论就明确说评论不足，走预先公布的默认路线；不编用户名、点赞数或投票结果。
- **不冒充官方**：不使用官方 Logo 做头像，不声称代表 Gemini、Google 或任何官方团队。
- **不无人审核直接发**：事实、版权、配音、音乐、画面和平台标注均需人工检查，账号登录与发布由你控制。

## 首周验收标准

首周不以“必须出爆款”为目标，而验证以下四件事：

1. 是否有人回答结尾的问题，而不是只刷无关梗；
2. 是否有人因为评论被采纳而再次回来；
3. 哪种题材的稳定表现高于本号中位数；
4. 单条制作时间是否可持续。

如果只有播放、没有关注与有效评论，优先修改账号实验规则和追更理由，不要先增加动画成本。
