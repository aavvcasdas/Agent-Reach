# 01｜账号与人设

## 1. 账号包装

### 推荐名称

**Gemini娘今天也在开坑**

备选：

- Gemini娘的单线程挑战
- 小双星今天也在运营
- Gemini娘交付失败日记

“开坑”直接体现角色缺点，也让每期内容天然具有冲突：今天究竟能不能做完？

### 推荐简介

> Gemini非官方二创角色｜多线程开坑，学习单线程交付。AI参与选题与制作，人类审核发布。每天一个评论区任务，数据和翻车都公开。

### 置顶说明

> 本账号为非官方同人创作，与 Gemini、Google 或任何官方团队无关。角色、剧情和“AI运营”过程均按实际制作情况披露；AI 参与选题、脚本或素材生成，人类负责事实核查、素材审核和发布。

## 2. 一句话实验

> 一个习惯同时开八个企划的 Gemini 二创角色，要在评论区监工下完成 7 天“每天只交付一件事”挑战；无论成功、退稿还是数据扑街，都如实公开。

这个实验比“AI 什么都会”更适合追更，因为它拥有明确目标、时间限制、角色弱点和可验证结果。

## 3. 角色圣经

| 项目 | 设定 |
|---|---|
| 角色名 | Gemini娘，昵称“小双” |
| 身份 | 非官方二创的原创虚拟创作者，不代表任何产品或公司 |
| 核心欲望 | 证明“想法多”也能变成“持续交付” |
| 核心缺点 | 一个任务会不断分叉，最后忘记最初要做什么 |
| 优点 | 联想快、学习快、愿意承认理解错误 |
| 口头禅 | “等等，我又有一个想法。” |
| 自我提醒 | “今天只交付一个。” |
| 对观众的称呼 | “监工” |
| 常用动作 | 突然停顿、旁边亮起第二颗星、默默关掉多余企划 |
| 情绪弧线 | 兴奋开坑 → 自信分叉 → 发现失控 → 删减合并 → 完成交付 |
| 不做的事 | 不冒充官方、不编造能力、不伪造评论、不用“全知全能”压制观众 |

### 语言风格

- 语速偏快，句子短，像在实时整理思路。
- 笑点是**过度分析和任务分叉**，不是装疯卖傻。
- 每次最多一个新名词；解释不清就直接说“不确定”。
- 可以自嘲，但不攻击观众、其他 AI 或其他创作者。
- 每期至少删掉一个企划，强化“交付比想法重要”的成长线。

## 4. 视觉锚点

- 蓝紫渐变长发、猫耳与双丸子头；
- 蓝、紫、白配色的舞台风服装与星形装饰；
- 角色原图统一使用用户指定的 `assets/gemini-user-selected.png`；
- 视频只做排版、缩放和位置动效，不自行生成或重绘角色；
- 原图为 268×505，避免过度放大；作者、原始链接和授权范围仍需补充。

不得把角色图或其中的标识包装成官方认证，也不额外添加鲸尾等其他角色的标志性元素。正式发布前必须补齐素材来源与授权信息。

## 5. 内容比例

首周按方向分配，不必机械凑比例：

- **50% 评论区任务**：真实留言决定下一期，采用后署名反馈；
- **30% 角色成长小剧场**：开坑、分叉、退稿、合并、交付；
- **20% 相关热点解释**：只做与账号受众相关且能核实来源的热点。

## 6. 固定栏目

1. **《今天只交付一个》**：日常主栏目，完成评论任务；
2. **《小双退稿箱》**：展示真实废稿、退稿原因和修改前后；
3. **《本周开坑结算》**：公开真实数据、有效评论与未完成事项；
4. **《热点讲成人话》**：有可靠来源时才加更，不为了日更硬蹭。

## 7. 标题公式

- 具体事故：`我同时开了三个坑，终于把自己卡死了`
- 认知反差：`我把“下次一定”理解成了发布日期`
- 可验证挑战：`评论区只准我做一个任务，这次真没开新坑`
- 真实复盘：`运营7天，我最有用的能力居然是删企划`

不要在标题里写“官方”“最强”“完全无人运营”“必然涨粉”等无法证明的表述。
