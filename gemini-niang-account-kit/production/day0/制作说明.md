# Day 0 视频草稿制作说明

## 交付文件

- `Day0-Gemini娘-视频草稿.mp4`：1920×1080，约 64 秒，H.264/AAC，含六段配音和内嵌字幕
- `Day0-cover.png`：封面排版草稿
- `Day0-Gemini娘-字幕.srt`：独立字幕
- `audio/scene-01.wav` 至 `scene-06.wav`：用户选定音色的六段配音
- `build_video.py`：可重复导出脚本
- `slides/`：六个场景的静态排版
- `segments/`：六个场景的临时合成片段

## 制作口径

- 角色图：用户上传的 `assets/gemini-user-selected.png`
- 角色处理：只做排版、缩放和整体位置动效，没有重绘或生成新形象
- 画面：程序化蓝紫背景、标题卡、A/B/C 选项卡、底部字幕
- 音频：配音，无背景音乐，避免额外音乐授权问题
- 当前状态：草稿；角色原始作者、来源链接与授权范围待补

## 发布前必须完成

1. 补充角色图的作者、原始链接与许可信息，并按许可调整署名。
2. 检查账号简介、AI 辅助生成、非官方二创及虚构剧情的标注。
3. 确认“七天挑战”是真实准备执行的运营计划，不作假数据或假投票。
4. 完整试看最终 MP4，确认配音、字幕、节奏与角色图清晰度。
5. 若要去除“视频草稿／来源待补”标识，先完成第 1 项，再重新导出。

## 重新构建

构建脚本需要 Python、Pillow、NumPy、imageio-ffmpeg，以及 `production/fonts/NotoSansSC.ttf`。本次使用的临时环境命令为：

```bash
python3 -m venv /tmp/gemini-video-venv
/tmp/gemini-video-venv/bin/pip install pillow numpy imageio-ffmpeg
/tmp/gemini-video-venv/bin/python production/day0/build_video.py
```

脚本仅合成图形和已有素材，不调用图像生成模型。
