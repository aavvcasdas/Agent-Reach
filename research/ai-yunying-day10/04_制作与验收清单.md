# Day10 制作与验收清单

## 0. 输入
- 文案：`scripts/Day10.md`
- 台词：`repo/Day10/Day10配音台词.txt`
- 渲染器：`repo/tools/day10制作/render_day10.mjs`
- 道具：`repo/tools/day10制作/repair_props.mjs`

## 1. 拷回仓库
将 `repo/` 下文件拷到 `ai-yunying` 根目录对应路径。不要覆盖 Day0–Day9 已发布资产。

## 2. 无声分镜
```bash
node tools/day10制作/render_day10.mjs --test
node tools/day10制作/render_day10.mjs --stills
```
检查：
- 9 镜覆盖 41 句；
- 首帧能看懂“科考站变食堂”；
- 修坏墙、委托单、发送键封印不挡字幕；
- 画面无粉丝/播放/收益/进度条/片尾卡。

## 3. 用户确认
给用户看抽帧或无声试剪，确认：
- 售后部主线是否接受；
- 笨鱼“只修不发”边界是否清楚；
- 首句钩子是否够快；
- 是否需要缩短到 50 秒左右。

## 4. 配音与实测时间轴
- 必须使用用户指定 WAV，不冒充晓伊。
- 原字节不改、无加速；按 Day9 流程做 ASR/RMS 对齐。
- 生成 measured=true 的 alignment JSON 与字幕 JSON。
- alignment.source_sha256 必须等于 WAV 的 SHA256。

## 5. 有声整片
```bash
node tools/day10制作/render_day10.mjs \
  --voice <用户指定WAV> \
  --alignment <实测alignment.json> \
  --subtitle-file <字幕.json> \
  --out Day10/成片/Day10_售后部开张_配音对齐版.mp4
```
检查：
- 全片解码无错误；
- 字幕与台词逐句一致；
- 末句后约 0.2s 停，无片尾卡；
- 抽帧检查电视/墙/字幕不漂移。

## 6. 发布物料
- 标题：《让它修电视，它把科考站修成食堂》
- 简介：非官方同人，AI生成，剧情演绎；上一集 Day9；本集开启售后部。
- 置顶：丢一句坏掉的话/标题/代码，本鲸挑一单给笨鱼。只修不发，修坏也挂墙。
- AI声明：平台开关 + 简介非官方同人。

## 7. 发布后回收
- 黄金1–2小时真回复。
- 收集可用委托，脱敏后进入 Day11/Day12。
- 记录内部指标：2秒跳出、收藏率、新增关注、评论委托数。
- 不把后台数据做到画面里。
